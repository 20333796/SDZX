# 项目任务管控

## 交付规则

每个工作包由责任角色在合并请求中附上实现路径、验收命令、截图或接口证据。没有通过 CI、迁移检查、依赖审计和相应人工验收的事项不得标记完成。课程内容负责人决定资料发布，平台研发组不能代替课程审核。

| 周期 | 工作包 | 责任角色 | 当前证据 | 完成条件 |
| --- | --- | --- | --- | --- |
| 1-4 | 首页、导航、资源目录 | 前端组、课程组 | `apps/web`、资源 API | 移动端验证；所有有效外链新标签打开；无链接资源有状态说明 |
| 1-4 | 工程、迁移、CI | 平台研发组、运维组 | Compose、Alembic、`.gitlab-ci.yml` | `npm run build`、`pytest -q`、迁移与审计通过 |
| 5-8 | 资料上传、解析、审核 | 平台研发组、课程组 | MinIO、Worker、知识片段状态机 | 上传文件可解析；未发布资料不可检索；课程组完成审核 |
| 5-8 | 引用问答与评测 | AI 组、课程组 | 词法检索、SSE 引用、Ollama 适配 | 建立 100 题评测集，引用覆盖率不低于 95% |
| 9-12 | 学情、研学、教师反馈 | 教学产品组、课程组 | `learning_tasks`、提交与教师反馈 API | 形成任务、依据、反馈和评分闭环；完成校内 OIDC 联调 |
| 9-12 | 测井与地学数据 | 专业应用组、课程组 | LAS/CSV、OpenLayers | 教师签字验收教学案例；GeoTIFF 完成坐标与元数据校验 |
| 13-16 | 认证、运维、试运行 | 运维组、信息化部门 | OIDC 适配、Helm、指标 | 校内 OIDC 联调、备份恢复、回滚演练和 50 并发压测通过 |

## 依赖与变更控制

新增第三方库必须记录许可证、来源和审计结果，并更新 `docs/third-party-notices/` 与 SBOM。`segyio`、Dify、敏感勘探数据、生产预测和全量三维仿真均不属于一期，变更范围前必须完成法务与数据授权评审。

数据库变更只能通过新 Alembic revision 提交。发布迁移先在预发布环境运行，应用版本必须支持迁移前后短暂共存。外部资源由课程组维护来源和版权说明，平台只记录资源 ID 和入口位置，不保存来源平台凭据。

## 周例会输入

各责任角色每周更新：完成证据、阻塞项、下周计划、风险等级和是否影响验收。阻塞三次周例会仍未解除时，由项目负责人决定调整范围、增加资源或延期；不得以未验收的占位实现替代承诺功能。
